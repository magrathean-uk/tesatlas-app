# Teslatlas custom Apple EULA

Teslatlas's custom End User Licence Agreement is now part of the published
[Teslatlas terms of use](https://teslatlas.eu/app/terms/), which sets out your
licence to use the app alongside Apple's own Licensed Application End User
Licence Agreement.

This file stays in this repository, at this path, so links that already point
to `EULA.md` keep working.
